# Spiekbrief Git en Github
## 1. clone, commit, push en pull
Met clone maak je een kopie van een bestaande repository van GitHub op je eigen computer.
Met commit sla je wijzigingen op in je lokale Git-repository.
met push stuur je je lokale commits van je computer naar de repository op GitHub.
Met pull haal je de nieuwste wijzigingen van de GitHub-repository naar je eigen computer.
## 2. een goed commitbericht
Goed voorbeeld: Voeg een inlogscherm toe aan de website.
Slecht voorbeeld: Ik heb iets aangepast.
## 3. maak een bestand
Een .gitignore-bestand geeft aan welke bestanden Git moet negeren.
## 4. Pull
wat er is gebeurt is dat ik de readme bestand oline heb aangepast en niet in vs code.
waardoor je altijd eerst moet pullen zodat je het nieuwste bestand heb en geen fout kan maken.
## 5. Terugdraaien 
het foute commit is niet uit de geschiedenis verwijdert want het is gepushed en daarom blijft het ook staan.
